# The project on 1 November 2026

These files describe the port as it was on 1 November 2026, before the performance work recorded in
[progress-log.md](../../progress-log.md). They are kept for their data: the state of each build up to 0.0.12, the open
issues of that time, and the research behind keeping Mesa as the renderer. They are reference, not a work queue. Paths
inside them point to where the files were then.

| File | What it holds |
| --- | --- |
| [CURRENT_STATUS.md](CURRENT_STATUS.md) | Builds Mesa004 to 012: what each changed and what hardware showed; the W0-W5 work packages |
| [ISSUES.md](ISSUES.md) | The issues open then: the native buffer crash, visual corruption, the title-idle movie, frame pacing and audio |
| [TCS360_CURRENT_BACKLOG.md](TCS360_CURRENT_BACKLOG.md) | The product requirements register: controls, co-op, audio, coverage |
| [TCS360_DEKO_IMPLEMENTATION_PLAN.md](TCS360_DEKO_IMPLEMENTATION_PLAN.md) | The execution harness, revision 2. Despite its filename, Mesa is the main route and Deko an inactive experiment |
| [RENDERER_DECISION.md](RENDERER_DECISION.md) | Why Mesa stays the main renderer, and how a Deko review should be scoped |
| [TCS360_MESA_REFERENCE_REVIEW.md](TCS360_MESA_REFERENCE_REVIEW.md) | Techniques from other Xbox 360 ports on the Switch, with their pinned revisions and limits |

The current state is at the end of [progress-log.md](../../progress-log.md), and the open issues are in
[known-issues.md](../../known-issues.md).
