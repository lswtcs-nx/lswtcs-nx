# Boot to the hub (the Cantina) on an existing save, then stand there 20 s.
# Rebuilt from the tester's own presses ([PAD] lines) in runs 112-117, which repeat the same menu path every session:
#   A (past the intro), START (title), DOWN + A, A, UP + A, then A once more and the hub loads ([LEVEL] Map\Map).
# The [PAD] lines are Switch buttons; menus read the face buttons by label (layout auto), so Switch A is the 360's A.
# Which menu items these are is not known; the timing between presses is the tester's, made a little longer.
# Not yet replayed on a console or in an emulator.
log boot_to_hub
waitlight 2000 120          # boot logos
press A                     # past the intro
waitloads 2 120             # the title screen has loaded ([LOADEP] #2 in every run)
wait 1500
press START                 # title: press start
wait 1200
press DOWN
wait 500
press A
wait 900
press A
wait 600
press UP
wait 500
press A
wait 5000                   # the tester waited 3.7-9 s here
press A                     # starts the hub's load
waitlevel Map 120
waitplay 5000 180           # in the hub, 5 s of play frames
capture
wait 20000                  # 20 s standing: a stable window for [WORK] and [CHAIN]
done
